# Arquivos para Impressão 3D

Os arquivos presentes nesta pasta correspondem ao modelo mecânico utilizado na fabricação da estrutura do protótipo CubEdu.

O projeto original foi baseado no modelo de CubeSat desenvolvido por Stephen Wells e disponibilizado no repositório *Wells CubeSat Open Design Repository* (WELLS, 2018). A partir desse modelo, foram realizadas adaptações dimensionais e estruturais para atender aos requisitos específicos do CubEdu, incluindo a integração dos componentes eletrônicos, sensores e sistema de alimentação empregados no trabalho.

**Referência:**

WELLS, S. *Wells CubeSat Open Design Repository*. 2018. Disponível em: <https://grabcad.com/stephen.wells-1>. Acesso em: 10 out. 2025.
